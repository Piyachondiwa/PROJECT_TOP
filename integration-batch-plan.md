# Integration Batch Plan

Goal: move Monster Garden from modular prototype pieces toward one playable vertical slice.

Priority batches:
1. Runtime contracts and safe initialization.
2. Town/NPC/Shop/Quest interaction flow.
3. Region travel and encounter spawning.
4. Garden growth, harvest, food, traits and monster skills.
5. Equipment and crafting flow.
6. Dungeon and boss flow.
7. Persistent save state for all progression.
8. Sprite and animation asset pipeline.
9. Final integration, balancing and bug pass.

Do not claim a feature is playable until it is wired into the runtime and has a visible user flow.
