# Integration Batch 3

Focus: turn the existing modular prototype into a more connected playable flow.

## Runtime connections to implement
- Town NPC proximity and dialogue
- Shop purchase flow
- Quest progress and rewards
- Region travel gates
- Garden plant -> harvest -> food effects
- Dungeon -> boss encounter
- Equipment/stat calculation
- Save/load of all persistent progress

## Rule
Prefer adapters and small integration functions. Do not duplicate gameplay rules in UI modules.
